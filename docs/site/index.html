START WITH A FOLDER

One command. Your workspace.

The installer selects your architecture, checks the release archive's SHA-256 and installs for the current user. No administrator privileges required.

Linux / macOS

curl -fsSL https://github.com/HSPK/folio/releases/latest/download/install.sh | sh

Windows PowerShell

irm https://github.com/HSPK/folio/releases/latest/download/install.ps1 | iex

Prefer to inspect scripts first? Read install.sh or install.ps1, or download manually. Checksums detect mismatched downloads; they are not a separate publisher signature.

  1. Choose a folder. Open Folio on Windows/macOS. On Linux: folio --serve /path/to/markdown.
  2. Create your local administrator. Set up a username and password on the first browser visit. No cloud signup.
  3. Write. Open a note or create one. Search with Ctrl/Cmd+P and save with Ctrl/Cmd+S.
A few honest boundaries

Folio 0.1.0 is early-stage: back up important notes. The app uses your existing browser, and the service is local by default. Sharing needs explicit permissions and a reachable server; Folio does not configure public hosting or TLS. Accounts, history and indexes are separate from the Markdown files.

macOS builds are ad-hoc signed, not notarized. First launch may need approval in Privacy & Security. Linux users may need to add ~/.local/bin to PATH. The app interface is currently English.
