专注页面，不纠结语法

Live 实时编辑、大纲、明暗主题、表格、公式与图片粘贴。需要时切换 Source、Compare 和 Read。

让想法逐步连接

全文搜索、YAML 标签、双链、反向链接、模板与收藏，让一个文件夹慢慢长成知识库。

需要时，再共同写作

项目、页面权限、公开链接与实时协作。私有文档不会因为支持协作就自动变成共享文档。

文件和工作流都属于你

普通 Markdown、版本历史、Git 差异、暂存与提交。定时提交推送是可选项，不要求使用托管同步服务。

同一份文件，两种视角

需要 Markdown 原文？
它一直都在。

Compare 把源码和预览放在一起。要求精确控制语法时用 Source； Live 编辑可能规范化 Markdown 写法。

从一个文件夹开始

一行命令，开始写作。

脚本自动选择系统与架构，校验发布包的 SHA-256，安装到当前用户目录，无需管理员权限。

Linux / macOS

curl -fsSL https://github.com/HSPK/folio/releases/latest/download/install.sh | sh

Windows PowerShell

irm https://github.com/HSPK/folio/releases/latest/download/install.ps1 | iex

想先检查脚本？阅读 install.sh 或 install.ps1，也可以手动下载。 校验和检查下载内容是否匹配，不等同于独立的发布者签名。

  1. 选一个文件夹。 Windows/macOS 打开 Folio；Linux 执行 folio --serve /path/to/markdown。
  2. 创建本机管理员。 第一次打开浏览器页面时设置用户名和密码，无需注册云端账号。
  3. 开始写。 打开笔记或新建一篇，Ctrl/Cmd+P 搜索，Ctrl/Cmd+S 保存。
也把边界说清楚

Folio 0.1.0 仍是早期版本，重要笔记请备份。编辑器使用已有浏览器，服务默认只在本机开放。 分享需要明确配置权限与可访问的服务地址，Folio 不替你配置公网托管或 TLS。 账号、历史和索引不保存在 Markdown 文件中。

macOS 发布包使用 ad-hoc 签名，尚未公证，首次运行可能需要在「隐私与安全性」中批准。 Linux 可能需要把 ~/.local/bin 加入 PATH。应用界面目前为英文。
